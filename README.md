## How I work

- **Start from a question,** not a dataset.
- **Keep the raw data,** with where it came from, so every number can be traced back.
- **Check before trusting:** totals that must add up, figures that must match published values.
- **Say what the data can't show,** next to what it can.

**Tools:** Python, pandas, data extraction and validation, simulation, time series, data visualisation,
Next.js and TypeScript for interactive stories, Git.
